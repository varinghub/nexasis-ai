# Nexasis AI Beta Feedback Guide

Thank you for testing Nexasis AI.

This public beta is intended to learn from real-world usage before wider distribution.

## Bug reports

Please include what you were trying to do, what you expected, what actually happened, whether it happens every time, Nexasis AI version, operating system/browser, Docker and Ollama versions, model involved, minimal reproduction steps, and relevant sanitized logs/screenshots.

## Feature requests

Describe the problem or workflow first. Explain what you want Nexasis AI to make easier and why it would help.

## General beta feedback

We especially want to know what works well, what feels confusing, which features you actually use or ignore, what feels slow, what would stop you using Nexasis AI regularly, and whether you would recommend it to another local-AI user.

## Security and privacy

GitHub Issues are public. Do **not** include API keys, passwords, access tokens, OAuth secrets, private documents, personal information, confidential prompts, internal infrastructure details, or complete application data files.

Sanitize logs and screenshots before posting them.
